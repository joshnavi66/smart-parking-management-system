How It Works

Min-Heap

Nearest vacant slot extracted in O(log n). Slot with smallest gate distance is always at the root.

AVL Tree

License plates indexed in a self-balancing BST. Guarantees O(log n) search regardless of insertion order.

B-Tree

Completed transaction receipts stored in a disk-optimized multi-way search tree for audit trails.

Graph + BFS

Parking lot is a weighted graph. BFS computes the shortest lane-by-lane path from entrance to bay.
